# macOS 26/27 kernel entry contract (2026-09-25)

Off-box. No laptop was touched.

Conclusion kept from this note: the macOS 27.0 kernel that runs under the hypervisor has no SPTM or TXM
in this boot. Reaching the console needs SCTLR_EL1.M set with the kernel's own bootstrap page tables.
That is a hypervisor change, not a field of the handoff structure. The handoff model the hypervisor
scripts build is in `tools/m2hv_entry_abi.py`.

The address-by-address trail behind this conclusion is kept private.
